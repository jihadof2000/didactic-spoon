# Drugs Alarm (سند) — مشروع أندرويد أصلي

تطبيق منبّه أدوية يعمل **حتى والتطبيق مغلق والشاشة مطفأة**. واجهة التطبيق هي نفس صفحة «سند» (HTML)
مضمّنة داخل التطبيق وتعمل بدون إنترنت، أما المنبّه نفسه فيُجدوَل عبر نظام أندرويد (`AlarmManager.setAlarmClock`).

## ماذا يفعل المشروع؟
- يرنّ المنبّه في وقت كل دواء بصوت المنبّه والاهتزاز، ويفتح التطبيق فوق شاشة القفل ويضيء الشاشة.
- عند ظهور البطاقة تتوقف نغمة النظام ويبدأ نطق «حان وقت دوائك» (أو الرسالة الصوتية المسجّلة).
- زر «أخذت الدواء» يلغي منبّه اليوم ويُبقي الغد، وزر «تذكير بعد قليل» يعيد التنبيه بعد 10 دقائق.
- تُعاد جدولة المنبّهات تلقائياً بعد إعادة تشغيل الهاتف أو تغيير الوقت/المنطقة الزمنية.
- حذف دواء أو تعديل أوقاته أو تاريخ انتهاء علاجه يُحدّث المنبّهات تلقائياً.

## الطريقة 1 — بناء الـ APK بدون Android Studio (عبر GitHub، مجاناً)
1. أنشئ حساباً على https://github.com ثم مستودعاً جديداً (New repository) باسم مثل `drugs-alarm`.
2. ارفع **كل محتويات هذا المجلد** (بما فيها المجلد المخفي `.github`) إلى المستودع:
   Add file ← Upload files، واسحب الملفات، ثم Commit.
   (تأكد أن `.github/workflows/build-apk.yml` ظهر في المستودع.)
3. افتح تبويب **Actions** ← اختر **Build APK** ← **Run workflow**.
4. انتظر 3–6 دقائق حتى يكتمل البناء (علامة ✓ خضراء)، ثم افتح عملية البناء ونزّل
   الملف المضغوط **DrugsAlarm-APK** من قسم Artifacts. بداخله `app-release.apk`.

## الطريقة 2 — Android Studio
1. ثبّت Android Studio ثم File ← Open واختر هذا المجلد، وانتظر انتهاء Gradle Sync.
2. من القائمة: Build ← Build Bundle(s) / APK(s) ← Build APK(s).
3. يظهر الملف في `app/build/outputs/apk/`.
(أو من الطرفية: `./gradlew assembleRelease` ثم `app/build/outputs/apk/release/app-release.apk`)

## التثبيت وأول تشغيل
1. انقل الـ APK إلى الهاتف وافتحه، واسمح بالتثبيت من مصدر غير معروف عند الطلب.
2. عند أول فتح اضغط **سماح** لإذن الإشعارات (أندرويد 13 فما فوق)، وللميكروفون عند تسجيل رسالة صوتية.
3. أضف دواءً بوقت بعد دقيقتين من الآن، **أغلق التطبيق وأطفئ الشاشة**، وانتظر: يجب أن يرنّ المنبّه.

## إعدادات مهمة في الهاتف لضمان وصول التنبيه (خصوصاً سامسونج/شاومي/هواوي/أوبو)
- الإعدادات ← التطبيقات ← Drugs Alarm ← **البطارية** ← «غير مقيّد / Unrestricted» (لا تُحسِّن).
- فعّل **التشغيل التلقائي / Autostart** (شاومي وأوبو وفيفو وهواوي).
- الإعدادات ← التطبيقات ← Drugs Alarm ← الإشعارات ← تأكد أن «منبه الأدوية» مفعّلة وبأعلى أهمية.
- أندرويد 14 فما فوق: إن لم يفتح التطبيق وحده فوق القفل فعّل
  «الإشعارات بملء الشاشة / Full screen notifications» من إعدادات التطبيق (سيرنّ المنبّه ويظهر الإشعار في كل الأحوال).
- لا تفعّل «عدم الإزعاج» دون استثناء المنبّهات.

## ملاحظات
- البيانات (الأدوية والسجلّ) تُحفظ داخل الهاتف فقط.
- ملف الـ APK الناتج موقّع بمفتاح debug ليُثبّت مباشرة. للنشر على Google Play أنشئ مفتاحك الخاص
  وغيّر `signingConfig` في `app/build.gradle.kts`.
- معرّف الحزمة: `com.fidaa.drugsalarm` — غيّره في `app/build.gradle.kts` (applicationId و namespace)
  وفي أسماء الحزم (package) إن أردت اسماً آخر.
- لتعديل واجهة التطبيق عدّل `app/src/main/assets/www/index.html` ثم أعد البناء.
- خط «عارف رقعة» مضمّن في التطبيق (ترخيص OFL) فلا حاجة للإنترنت.
- التنبيه لا يرسل رسالة SMS تلقائياً للمرافق عند النسيان (هذا يتطلب أن يضغط المستخدم على رابط الرسالة).
